a radar for pre-token crypto protocols: which one is worth farming next, what it may be worth, and exactly what to do about it. reads a frozen defillama snapshot, scores every protocol with a stated value model, and writes a sortable dashboard with concrete farm plans.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```

needs node 22.18 or later, standard library only, no network. runs twice with byte-identical output.
